# V51.9.52 — Motion feel: measured easing, ticking counters, ripple stagger

Why: the motion-core-lite crop of "motionmaxxing" (Apache-2.0) offered measured motion curves and a frame-stepped counter. They went into the engine that draws Motion Class, reels and the offline pack (`reels/motion/engine.ts`), not the older `math/animation/runtime.ts` the crop's README pointed at. Attribution: `reels/motion/NOTICE-motion-core.md`, licence in `third-party-licenses/`.

- **Measured easing per kind of action** (`ease.softLand / glide / softInOut / accelExit`, `FEEL`): things that land (appear, write, rule, arrow, strike, tick, focus halo) decelerate softly; moves and merges glide; colour, dim, undim, fill and unfocus blend symmetrically; fade-outs accelerate away. Every curve starts at 0 and ends exactly at 1, so the board at the end of every step is unchanged. Unchanged on purpose: plane / shape morphs, the camera, box tracing and the pop overshoot of `appear` (smooth in-out and overshoot suit them).
- **Ticking counters** (`countSteps`, `Motion.count`): a number ticks one value per frame (big steps first, then smaller, never back) and lands exactly on its value; no rolling, no easing between values. Used for the HCF and LCM results (e.g. LCM: 1 → … → 18 → 27 → 34 → 36 as the line is written). Results under 3 are written directly. The count runs only while the result is being revealed; the line is true once it has landed.
- **Ripple stagger** (`rippleOnsets`): in `appear` / `write` with a stagger, the first gap is 1.5× the rest, so the lead item lands alone before the rest ripple in.
- Not adopted: the dead-air check (voiced classes are meant to be still while the teacher speaks) and word sync (the voice pipeline has no real word timings yet: Edge word boundaries are off and the engine ignores the estimated ones).
- Tests: 9 new. Every curve exact at both ends, in range and never going back; landing vs leaving shape; the verbs use them; ripple onsets; counter exact, monotone, whole and big-steps-first for several spans, including counting down; the count verb's text before, during (no roll) and after; later swaps kept; HCF/LCM samples end on the true values in both languages; same pictures in English and Malayalam. All 793 motion-class and reel tests pass (every existing layout, overlap and timing test included). Whole suite: 1072 tests. The 17 old failures are unchanged; one older math test timed out once under full-suite load and passes 3/3 alone. `tsc` has the same 68 old errors.
- Seen by eye: frames of the LCM step as the number ticks up.
- Not run here: the feel in real playback at 30 fps with voice (frames only); judge it in the class and tell me if a curve feels too fast or too soft — each is one number.
